# v1.1.10

这一版修的是一处「状态页说假话」的问题：明明监控在跑，它却报「未运行」。

## 现象

Windows 上判断「监控进程在不在」，看的是它的命令行。原来的判据要求命令行必须长成
`-File "…\envproxy.ps1"` 这样——**路径两侧要带引号**。

引号是启动方式决定的：产品自己起的监控带引号（路径里有空格也必须带），但你自己在终端里
敲一条 `powershell -File D:\EnvProxy\win\envproxy.ps1` 起的监控**没有引号**。

于是这样起来的监控，在产品眼里等于「不存在」：

- 状态页报「监控进程 : 未运行」——其实它正跑着；
- 打开菜单选「安装 / 修复」，安装器以为监控没在跑，要起一份新的；可单实例锁被旧的那份占着，
  新的一份起不来，于是安装器报「监控进程：未能确认运行」。

## 这一版怎么改的

判据改成看**实质**，不再看拼写：命令行结尾跑的是本脚本、而且没有子命令，就算监控。
带引号、不带引号都认。

带子命令的进程（`-Status`、`-Install`、`-Stop`）仍然不算监控——那种是「用一下就退」的进程。

## 兼容性

- 变量集合、注入与删除的判据、去抖与迟滞语义都没变。
- macOS 侧本来就是按实质判断的，这一版是让 Windows 侧与它对齐。
- 变的只有这一处：状态页与安装器不再认不出已经跑着的监控。
- 配图里圆圈中的数字重新对齐了（原来整体偏低约 2 像素，换了字体会更明显）。

## 升级方式

打开菜单选 `5 检查更新`。
