# v1.2.0

菜单里多了一个「帮助」，忘记怎么用的时候有地方查了。

## 这次加什么

### 6 帮助

装完之后放着不管，过几个月再想改点什么，往往想不起来命令怎么写。现在不用翻文档：打开菜单选 `6`，常用命令、三种窗口的区别、几个容易踩的坑，一屏看完。

Windows 和 macOS 都有，也可以在终端里直接调：

- Windows：`powershell -ExecutionPolicy Bypass -File envproxy.ps1 -Help`
- macOS：`bash envproxy.sh help`

帮助里除了命令，还写清了几个最常问的问题：为什么旧窗口要按一次回车、为什么终端还是不能翻墙、只想让某一个窗口直连怎么办。连「Windows 上要写 `curl.exe` 而不是 `curl`」这种细节也放在里面了，那是个很容易踩的坑：PowerShell 把 `curl` 认成了 `Invoke-WebRequest` 的别名，直接敲会报参数错误。

## 这次修什么

### 菜单可能少印一项

菜单的显示和它实际接受的编号是两份各自维护的清单，加功能时容易只改一处。现在两者共用同一张表，加一项就一定会显示出来，不会再出现「功能做了但界面上看不到」。

### 文档与代码不一致的若干处

- 日志上限写成 1MB，代码是 200KB
- 一处写「每 60 轮」，代码和另一个语言版本都是 30
- 「访问 7 个站点才算通」——实际是任意 1 个通就算
- 「改名后监控继续跑」——实际是监控会自己退出并清除代理变量，改名后要用「安装 / 修复」或等下次登录
- 「重复装连文件时间都不改」——实际会重写开机启动文件
- 「每 2 秒」——直连状态实际是 3 秒
- 「搜索范围是用户目录向下 6 层」——实际只搜桌面、文档、下载、OneDrive、`.config` 这几个位置

这些都不影响程序怎么运行，但会让人对不上号。现在全部按实际行为改写。

### 配图

几张卡片上的文字没跟上，其中「技术边界」那张画的其实是另一套内容。现在中英十张图全部按当前版本重画。

### 测试里有一条假的

「会不会误删你自己的代理」这段有四条断言，但它准备的数据有问题，四条走的其实是同一个分支：把判断逻辑整段删掉，它们照样全部通过。现在每条都摆好真实状态、只改被测的那一项。也验证过了：故意把判断改坏，测试立刻报红。

### 帮助文档在 PowerShell 里跑不起来

帮助里写的是 `curl --noproxy "*"`，这条命令在 Windows 上跑不起来：`curl` 在 PowerShell 里是 `Invoke-WebRequest` 的别名。现在写 `curl.exe`。README 同一行原先标着「Windows / Mac」共用，现在拆成两行各写各的。

## 升级

打开菜单选 `5 检查更新`，同意就会装。不用为升级开翻墙软件。

升级只替换程序文件，你的日志、`monitor\` 里的运行标记都不动。
