## v1.0.0：首个版本

终端自动翻墙：翻墙软件开着，终端自动走代理；关掉，终端自动恢复直连。Windows 和 Mac 通用，
零依赖，不需要管理员权限，全程零操作，系统配置零残留。

### 它会做什么

- 翻墙软件开着的时候，自动把代理写进环境变量，终端里的 `git`、`npm`、`curl` 这类工具跟着走代理；
- 翻墙软件关掉之后，自动把这几个变量删干净，终端立刻回到直连，不会留下"连不上"的残留；
- 常驻监控每 2–3 秒看一眼，判"真的在翻墙"要过三道检查：端口在听、握手能过、真能连出去；
- 变量整套同进同退：Windows 5 个，macOS 9 个（含小写拼写）；判"断"保守（连续 3 次失败才认定），判"通"立刻认回。

### 安装（3 步）

1. 下载你平台的包（Windows 下 `EnvProxy-win.zip`，Mac 下 `EnvProxy-mac.tar.gz`），解压到任意位置，文件夹随便改名；
2. 进 `win` 双击 `打开菜单.cmd`（Mac 进 `mac` 双击 `打开菜单.command`），再选 `1 安装 / 修复`；
3. 看到"监控进程：已启动"就装好了。

### 一个菜单

`win\打开菜单.cmd`（Mac 是 `mac\打开菜单.command`）是每端唯一的双击入口，进去按编号选：

| 编号 | 作用 |
| --- | --- |
| `1 安装 / 修复` | 万能修复：注册开机自启、启动监控、当场校正一次变量 |
| `2 查看状态` | 只读：监控、自启动、翻墙状态、变量、版本、最近日志 |
| `3 停止监控` | 暂停：删变量恢复直连，保留自启动（下次开机自动回来） |
| `4 一键恢复` | 卸载：删变量（只删自己写下的，按安装时的快照还原你的原值）+ 删自启动、定位器、路径记录，会先问日志留不留 |
| `5 检查更新` | 查最新版并显示这一版改了什么，你同意才装 |

### 升级认得出三种文件夹

| 你的文件夹 | 怎么认出来的 | 检查更新会怎么做 |
| --- | --- | --- |
| 开发副本（`git clone` 下来的） | 有 `.git` | 只读不动，提示你在仓库里执行 `git pull` |
| 源码包（删掉了 `.git` 的克隆，或很早以前的旧包） | 有 `.github`、无 `.git` | 先问你一句：当安装包用就更新并清理源码文件（只问一次），自己改代码就一个字节都不动 |
| 安装包（Releases 里下载的） | 两个都没有 | 正常更新 |

菜单里选"查看状态"会直接告诉你当前是哪一种。

### 这一版包含

- Windows 与 macOS 两套实现，使用者看到的行为一致；
- 零依赖与明文脚本：只用系统自带的东西，不打包二进制，不碰系统代理，不需要管理员；
- 安装先快照、卸载按快照还原：只回收自己写下的值，公司内网机原来配过的代理装完再卸还在；
- 更新走 GitHub Release：下载先过五项校验，覆盖前备份、失败逐文件回滚；安装、更新、停止、卸载共用操作锁，同时点两个不会打架；
- 改用户配置文件必须成对才动手：标记缺一半就一个字节都不改，动手前先备份；
- 搬家与自退：文件夹搬走或删掉，残留变量跟着清干净，新终端不会读到过期代理；
- 编码、安装包内容、双语文档、契约常量、配图一致性与文件模式都有 CI 门禁守着，文档里的数字都从代码取值；
- 回归自检进门禁：纯函数、hook 护栏、归属判定、注入回收、快照还原，每次提交都跑一遍。
