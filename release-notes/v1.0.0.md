# v1.0.0

第一个正式版本。

## 它解决什么问题

翻墙软件只管浏览器，不管终端。`git`、`npm`、`curl` 这些命令行工具只认环境变量——翻墙软件开着，
它们照样连不上。

EnvProxy 常驻在后台盯着：真在翻墙就把代理写进环境变量，翻墙软件关了就把变量删掉。不用手动配，
也不用记得关。

## 这一版有什么

- **Windows 与 macOS 两端，行为一致**：检测到代理才注入，断开就删除；换端口、换翻墙软件都不
  用改配置。
- **零依赖**：Windows 用系统自带 PowerShell，Mac 用系统自带 bash 与系统命令，什么都不用装，
  也不需要管理员权限。
- **不认品牌，只认"谁真的在提供代理服务"**：不写死端口号、不写死进程名。三层验证全过才算数
  ——端口在听、它真的能转发请求、通过它能访问外网。
- **你自己的配置不会丢**：装之前先给同名环境变量拍快照，卸载时按快照还原；系统级变量和系统
  代理从来不碰。
- **菜单五个动作**：安装 / 修复、查看状态、停止监控、一键恢复、检查更新。第一项是万能修复。
- **升级不必开翻墙软件**：装之前对一遍校验值，对不上就不装；更新只动程序文件，不碰你的东西。

## 已知边界

- **纯 TUN 模式不注入**：流量已经被全局接管，终端本来就通，这时检测不到本地代理端口属于正常，
  不是故障。
- **"断开连接"不等于退出软件**：多数翻墙软件的断开按钮不停内核，端口还活着。以"能不能真的
  翻出去"为准。
- **搬到搜索范围之外要手动接管一次**：打开菜单选"安装 / 修复"即可，其余情况全自动。
- **已经开着的终端窗口不会变**：变量写进系统环境后只对新开的窗口生效，重开一个就行。

## 安装

下载你平台的包 → 解压到任意位置（文件夹随便改名）→ 进 `win`（Mac 进 `mac`）双击菜单 →
选 `1 安装 / 修复` → 看到"监控进程：已启动"就装好了。
