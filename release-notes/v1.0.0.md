## v1.0.0：第一个公开发布版

这是 EnvProxy 的第一个对外版本。以前它只在自己机器上跑，现在整理成解压就能双击用的东西，
所以第一次发布就从 1.0.0 开始编号。

### 它会做什么

- 翻墙软件开着的时候，自动把代理写进环境变量，终端里的 `git`、`npm`、`curl` 这类工具跟着走代理；
- 翻墙软件关掉之后，自动把这几个变量删干净，终端立刻回到直连，不会留下"连不上"的残留；
- 常驻监控每 2–3 秒看一眼，判"真的在翻墙"要过三道检查：端口在听、握手能过、真能连出去；
- 全程零操作、零残留、不需要管理员权限。

### 安装（3 步）

1. 下载 `EnvProxy.zip`，解压到任意位置，文件夹随便改名；
2. 进 `win` 双击 `1-安装.cmd`（Mac 进 `mac` 双击 `1-安装.command`）；
3. 看到"监控进程已启动"就装好了。

### 五个按钮

| 按钮 | 作用 |
| --- | --- |
| `1-安装` | 万能修复：注册开机自启、启动监控、当场校正一次变量 |
| `2-停止监控` | 暂停：删变量恢复直连，保留自启动（下次开机自动回来） |
| `3-一键恢复` | 卸载：连自启动、定位器、路径记录一起清掉，会先问日志留不留 |
| `4-查看状态` | 只读：监控、自启动、翻墙状态、变量、版本、最近日志 |
| `5-检查更新` | 查最新版并显示这一版改了什么，你同意才装 |

### 这一版包含

- Windows 与 macOS 两套实现，使用者看到的行为一致；
- 零依赖：只用系统自带的东西（Windows 自带 PowerShell、macOS 自带 bash 与 curl）；
- 更新走 GitHub Release，安装包随包带说明，更新前先告诉你会改什么；
- 编码、安装包内容、双语文档、契约常量、配图一致性与文件模式都有 CI 门禁守着。
