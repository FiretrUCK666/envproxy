# v1.0.0

第一个正式版本。

## 它解决什么问题

翻墙软件只管浏览器，不管终端。`git`、`npm`、`curl` 这些命令行工具只认环境变量——翻墙软件开着，它们照样连不上。

EnvProxy 常驻在后台盯着：真在翻墙就把代理写进环境变量，翻墙软件关了就把变量删掉。不用手动配，也不用记得关。

## 这一版有什么

- **Windows 与 macOS 两端，行为一致**：检测到代理才注入，断开就删除；换端口、换翻墙软件都不用改配置。
- **零依赖**：Windows 用系统自带 PowerShell，Mac 用系统自带 bash 与系统命令，什么都不用装，也不需要管理员权限。
- **不认品牌，只认「谁真的在提供代理服务」**：不写死端口号、不写死进程名。三层验证全过才算数——端口在听、它真的能转发请求、通过它真的能访问外网。
- **还要证明「不靠它打不开」**：光能通不算数，得同时满足「经代理拿到正确回应」和「本机直连拿不到」。否则碰上「那个检测网址本来就能直连打开」的情况，一条已经死掉的代理会被判成正在翻墙，然后把死代理铺满你所有终端。
- **不知道就说不知道**：DNS 解析失败、整条直连不通、拿到不该回的回应，都算「问不出来」，不算证据。这条是上面那道的保险：把「问不出来」当成「被墙」，等于给坏代理发免费通行证。
- **结论会过期**：判断结果带有效期（10 分钟）和网络指纹（默认网关 + 本机 IP）。换 Wi-Fi、插网线、开关虚拟网卡，指纹一变就重新问。
- **你自己的配置不会丢**：装之前先给同名环境变量拍快照，卸载时按快照还原；系统级变量和系统代理从来不碰。**装之前就有的值，哪怕长得像我们的也永远不动**——你自己设的 `NO_PROXY=localhost`、自己挂在 127.0.0.1 上的 mitmproxy，都不会被当成残留删掉。
- **判「断开」很保守，判「连上」很快**：要连续失败满 10 秒、且至少 3 次探不到才算断开；只要能通一次就立刻不再算断。断开要删变量并通知全系统，代价比多等一会儿大得多。
- **探测量守着承诺**：一切正常时每个端口 15 秒最多探一次，只读响应头不读正文，每次不到 1KB。只有在结论真的变了的时候才临时加密观察，事后自动回落。
- **菜单五个动作**：安装 / 修复、查看状态、停止监控、一键恢复、检查更新。第一项是万能修复。
- **升级不必开翻墙软件**：装之前对一遍校验值，对不上就不装；更新只动程序文件，不碰你的东西。

## 三块高级功能

菜单里选 `5` 进的就是这里，各自解决一个具体麻烦。

- **给某个程序定规矩**：给某个程序造一个图标，双击它时先准备好环境再启动真程序。可以让它单独走代理，也可以让它单独不走代理，原程序一个字节不动。走代理的图标认的是一个固定入口，所以翻墙软件换端口也不用重建。
- **网络与代理修复**：翻墙软件被强行关掉（直接关机、断电、结束进程、崩溃）时，系统里还留着「浏览器请走 127.0.0.1:7078」，而那个端口上已经没有程序了，于是连国内网站都打不开。这一屏按「网络 → 浏览器 → 终端」一起查三处：系统代理、终端工具的配置文件（`git config`、`~/.npmrc` 这类，它们的优先级高于环境变量）、网址解析。只关掉那个真的坏的开关，别的一个字节不动；动手前留一份原样，还能改回去。
- **本工具管不到的地方**：WSL 和 Docker 各有一套自己的网络设置，这里只讲怎么配，不动你的设置。

## 已知边界

- **纯 TUN 模式不注入**：流量已经被全局接管，终端本来就通，这时检测不到本地代理端口属于正常，不是故障。这类机器上「不靠它打不开」那道证明会整体失效，工具会退回「经代理拿到回应就算通」并在日志里记一笔。
- **「断开连接」不等于退出软件**：多数翻墙软件的断开按钮不停内核，端口还活着。以「能不能真的翻出去」为准。
- **搬到搜索范围之外要手动接管一次**：打开菜单选「安装 / 修复」即可，其余情况全自动。
- **已经开着的终端窗口不会变**：变量写进系统环境后只对新开的窗口生效，重开一个就行。
- **安全软件可能拦脚本**：个别杀毒 / EDR 会拦截脚本发起的网络探测，表现为一直检测不到代理。把本程序加入白名单即可，程序本身不做任何提权操作。

## 等多久

| 情形 | 大约 |
| --- | --- |
| 翻墙软件开了，新开终端 | 约 6–10 秒 |
| 完全退出翻墙软件 | 约 8 秒 |
| 只是「断开连接」（软件还开着） | 约 15–50 秒 |
| 断开后又连回来 | 约 10–25 秒 |
| 换了代理端口 | 约 10 秒 |

数字由代码里的常量算出来，不是手写的。

## 安装

下载你平台的包 → 解压到任意位置（文件夹随便改名）→ 进 `win`（Mac 进 `mac`）双击菜单 → 选 `1 安装 / 修复` → 看到「监控进程：已启动」就装好了。
