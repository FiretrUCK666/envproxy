## v1.1.0：护住用户已有的东西

安装先给同名变量拍快照再覆盖，卸载按快照还原；只删本工具自己写下的值，别人的配置不动。
Mac 安装三步各自验完再报结果，卸载末尾回读复检；全端口扫描同时开工、统一截止，端口多的机器也不慢。
回归自检进门禁：纯函数、hook 护栏、归属判定、注入回收、快照还原，每次提交都跑一遍。

### 它会做什么

- 翻墙软件开着的时候，自动把代理写进环境变量，终端里的 `git`、`npm`、`curl` 这类工具跟着走代理；
- 翻墙软件关掉之后，自动把这几个变量删干净，终端立刻回到直连，不会留下"连不上"的残留；
- 常驻监控每 2–3 秒看一眼，判"真的在翻墙"要过三道检查：端口在听、握手能过、真能连出去；
- 变量整套同进同退：Windows 5 个，macOS 9 个（含小写拼写）；判"断"保守（连续 3 次失败才认定），判"通"立刻认回。

### 安装（3 步）

1. 下载 `EnvProxy.zip`，解压到任意位置，文件夹随便改名；
2. 进 `win` 双击 `1-安装.cmd`（Mac 进 `mac` 双击 `1-安装.command`）；
3. 看到"监控进程已启动"就装好了。安装先给已有的同名变量拍快照，卸载时按它还原。

### 五个按钮

| 按钮 | 作用 |
| --- | --- |
| `1-安装` | 万能修复：注册开机自启、启动监控、当场校正一次变量 |
| `2-停止监控` | 暂停：删变量恢复直连，保留自启动（下次开机自动回来） |
| `3-一键恢复` | 卸载：删变量（只删自己写下的）+ 删自启动、定位器、路径记录，按快照还你原来的值，会先问日志留不留 |
| `4-查看状态` | 只读：监控、自启动、翻墙状态、变量、版本、最近日志 |
| `5-检查更新` | 查最新版并显示这一版改了什么，你同意才装 |

### 这一版包含

- 安装快照、卸载还原：公司内网机原来配过的代理，装完再卸还在；
- 改用户配置文件必须成对才动手：标记缺一半就一个字节都不改，动手前备份；
- 自退与定位器兜底：文件夹搬走或删掉，残留变量跟着清干净，新终端不再读到过期代理；
- 全端口扫描并发化：耗时不随端口数线性增长；
- 回归自检：纯函数、hook 护栏、归属判定、注入回收、快照还原，门禁每次都跑；
- 更新临时目录用完就删；Mac 可疑端口扫描一次 awk 出结果，空转更省电。
