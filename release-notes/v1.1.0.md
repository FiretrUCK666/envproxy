# v1.1.0

这一版把「终端工具连不上」这一整类问题收干净了：能查出来的工具从 3 个变成 13 个，能替你改的从「删掉一行」变成「按工具该有的样子改」。顺带修好了 macOS 上一个一直存在、但没人发现的故障。

## 这一版修掉的大问题

- **macOS 上的状态页、问题报告、以及新加的 JSON 输出，之前其实是坏的。** macOS 自带的是十多年没更新过的旧版 bash，它碰到某一种代码写法会从那一行起把整个文件判为语法错误——于是那几屏在真机上是「命令不存在」。Windows 和 Linux 上都看不出来，所以一直没被发现。这版修好了，并且加了一道自检：用当前系统的 bash 把每个脚本解析一遍，关键函数缺一个就报红。之后的版本不会再悄悄坏掉。
- **改端口不会再把引号写进你的配置。** 同一种旧版 bash 在处理「替换字符串」时会保留引号，于是本来该是 `127.0.0.1:9999` 的地方会变成 `"127.0.0.1:9999"`——配置被改坏，而屏幕上看不出来。已改成两种 bash 上结果一致的写法。

## 终端工具的覆盖

- **从 3 个工具扩到 13 个**：`git`、`npm`、`curl`、`cargo`、`pip`、`wget`、Yarn（两个版本）、Gradle、Conda、Maven、NuGet、SSH。它们的配置文件格式各不相同（`key=value`、YAML、嵌套 YAML、yarnrc、XML、ssh 配置），现在都能读懂。
- **修法按工具分三档**：自己认环境变量的（`git`、`npm`、`curl` 这类）删掉那一行，让它们回到读变量；Gradle、SSH 有代理在跑就改成当前端口、没有就删掉；Conda、Maven、NuGet 的结构不允许删一半，只改端口那一行，没有代理时只报告不动手。
- **改前整份留底**，按 `r` 能撤回最近一次；改端口只替换地址那一段，账号密码与协议都不动。
- **新增「只认 SOCKS 的端口」检查**：有些客户端只开了 SOCKS 口，而终端工具只认 HTTP 代理，于是「明明有代理，工具却说没有」。这一屏会把它指出来，并在客户端里该开哪个开关上说清楚。
- **macOS 的网址解析检查从空壳变成真实现**：按网络服务读系统 DNS，只判「指向本机 / 虚拟网段、而 53 端口没人应答」这一种；判活用的是被动观察，不会因为 macOS 的 DNS 主要走 UDP 就误报。

## 状态可以给脚本读了

`envproxy.ps1 -Status -Json`（Mac 是 `status --json`）输出**一行纯 ASCII 的 JSON**，字段固定，给脚本、状态栏、批量部署用。`state` 有三种取值，`unknown` 表示「这一轮没读到端口」，不是「没有代理」——三态不会被塌缩成两种。

## 两处默认值的修正

- **例外清单补上了内网后缀与云元数据地址**：`.local`、`.lan`、`.internal`、`169.254.169.254`。这三类永远不是公网域名，送进隧道一定错。**没有写网段**——不同工具解析规则不一样，写了多半不生效，还会让人以为内网已经全覆盖。
- **判断「这台机器还在不在线」不再只问一家**：改成三条网址的池，任一条拿到回应就算在线。只依赖一家时，企业内网或海外网络会被读成「整机离线」，一个好节点因此被判死。

## 菜单与说明的重新整理

- **高级功能里的 Docker 只在一页讲。** 原来「Docker 里也想翻墙」与另一个页面各讲一半，用户会以为漏了。现在 Docker 有自己完整的一页，Maven / Gradle / SSH 有另一页。
- **Maven / Gradle / SSH 那一页给了完整写法**：文件路径、要加的那几行、git@github.com 这种地址的两套解法（换成 https 地址，或让 SSH 自己交给代理），都直接可抄。
- **Docker 那一页补上了 `~/.docker/config.json` 到底怎么写**，包括「文件里还有别的设置就只加这一段、别整个替换」。
- **帮助第 9 条改成「指路」**：它只回答「哪几个工具要自己填、去哪个页面抄」，不再半截半截地复述写法。同一件事在两个地方各写一遍，迟早有一个会过时。
- **Mac 版补上了 Docker 那一页**（原来只在别的页面里带一句），高级功能从 5 项变成 6 项。
- **状态页「终端同步」那行说得更直**：`cmd` 窗口没有提示符钩子可用，只能重开窗口——这一句现在直接写在屏幕上。

## 已知边界

- **macOS 没有固定入口**：Windows 版在本机开了一个永远不变的地址（`17099`），所以那些「把地址写进自己配置里」的程序填一次就不用再改。macOS 没有这一层，填的是当前端口；翻墙软件换了端口要改一次，改的时候可以让「网络与代理修复」帮你把那几行改到当前端口。
