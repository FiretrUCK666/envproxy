# v1.1.0

## 更新不再必须先能翻墙

这是这一版唯一的一等大事。

以前更新只有一个源：GitHub。到不了 GitHub 就检查不到新版、也下不了包——而这恰恰是这个工具的用户最可能遇到的情况：翻墙软件还没连上，或者正好挂了。工具本身是用来配合翻墙的，更新却要求你先能翻墙，这个循环是断的。

现在多了一个墙内可达的镜像源，更新入口会自己找路：

- 先问官方源，官方源不通就问镜像源，谁先答上来就用谁；
- 版本号和安装包来自同一个源，不会串源；
- 两个源都是项目自己的仓库，校验口径一个字都没放宽：版本号要对得上、本平台入口要在、编码红线要过，任何一项不过依然是"安装区一个字节都不动"。

连不上时的提示也从「网络不可达或 GitHub API 限流」改成了实话：「所有更新源都不可达」。

## 顺带

- 「查看状态」里的版本检查同样会自己换源——它和「检查更新」共用同一段逻辑，不是两套。
- 更新成功后会显示这一版是从哪个源拿到的。
- 旧的提示「请确认 GitHub 可达后重试」不再出现：那是只有一个源时才需要说的话。

## 升级方式

老版本需要先能连上 GitHub 更新一次（或者手动下载安装包覆盖一次），才能获得「以后不翻墙也能更新」的能力——旧版本的代码里根本没有镜像这个选项，这是绕不过去的一次性跨越。

从这一版开始，就再也不需要了。
