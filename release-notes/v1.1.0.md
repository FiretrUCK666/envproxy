## v1.1.0：Mac 五个传话壳退场，终端命令直调入口

**升级上来不用做任何事。** 旧的五个传话脚本会在更新时自动清除。原来记着老命令的手感换一下：

- `bash mac/install.sh` → `bash mac/envproxy.sh install`
- `bash mac/stop.sh` → `bash mac/envproxy.sh stop`
- `bash mac/uninstall.sh` → `bash mac/envproxy.sh uninstall`
- `bash mac/status.sh` → `bash mac/envproxy.sh status`
- `bash mac/update.sh` → `bash mac/envproxy.sh update`

`--purge` / `--yes` 照旧跟在新命令后面。双击用户不受影响，五个按钮照常点。

### 这一版包含

- `mac/` 根下删掉 `install.sh / stop.sh / uninstall.sh / status.sh / update.sh`：
  它们只做"进目录 + 转调入口"，零逻辑，留着只是多一道手；
- 五个 `.command` 双击壳改为直调 `envproxy.sh` 对应子命令，与 Windows 侧"壳直调入口"对齐；
- 立一条入口层家规：`win/` 与 `mac/` 根下只放用户直接用的入口（双击壳、主入口、定位器模板），
  其余一律进 `lib/`，以后根下不会再长出这类传话文件；
- 双语 README、CONTRIBUTING、门禁与项目说明随之同步，无行为变化。
