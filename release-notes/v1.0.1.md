# v1.0.1

这是一个更正版本：第一版里那张「菜单每个选项动什么」的对照图是错的。

## 错在哪

那张表原本是按四个动作设计的（安装、停止、恢复、更新），后来加进了「查看状态」这一行，
但下面的数据没有跟着往下挪——于是整列错位了一格。

结果就是图上写着：

- 「查看状态」会清掉监控进程和环境变量——它其实什么都不动；
- 「停止监控」会把开机自启和定位器一起清掉——它其实都留着；
- 「一键恢复」什么都不动——它其实全清。

三条全反了。现在每一格都对着代码重新核过。

## 顺带改准的两处

- **环境变量那一格的记号**：安装不是简单地「保留」或「清掉」，而是按当前有没有在翻墙来校正，
  所以换成了 `±`，并在图例里写明「看当前有没有在翻墙」。
- **日志那一格的说明**：日志一律保留，只有「一键恢复」会问你一句要不要连日志一起删。

## 另外两处

- **首页那张大图**的中文写「关掉，终端立刻恢复直连」。实际退出翻墙软件后大约要 5 秒才删完变量，
  「立刻」两个字把话说满了；英文版本来就没有这个词。改成「自动恢复直连」，两边对齐。
- **一条自检用例**会跟着这台机器的状态摇摆：它验证「连不上时归成哪一类失败」，可本机正好开着
  翻墙软件时代码会经它重试一次，代理替我们回一个 502，就被归成「对方服务端出错」。现在这条
  用例把「有没有活代理」固定成没有，跑一百次都是同一个结果。

## 这一版改了什么

改的是 README 里的配图（中英各一张）和一条自检用例，程序本身一个字节都没动。

## 升级方式

打开菜单选 `5 检查更新`。
