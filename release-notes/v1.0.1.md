# v1.0.1

把"断开之后多久删变量"调回正常速度，并把一条容易踩到的边界补进说明。

## 这一版改了什么

- **"断开连接"后删变量更快了**：以前要等到连续 3 次探测都失败才认断开，而每次探测之间隔着
  15 秒，于是实际要等 50 秒上下，节点卡住时应答超时还能拖到 60 秒开外。
  现在改成"连续失败满 10 秒、且至少 3 次探不到"——判定仍然保守，但不再被采样间隔拖住。
  实测只断开的情形从约 50 秒降到三十几秒，节点卡死的最坏情形从约 62 秒降到约 46 秒。

- **断开后又连回来，认得更快**：以前最长要等约 17 秒才把变量补回去，现在约 3 秒。
  刚下完结论的一段时间里会看得更勤，判错了能马上改回来。

- **探测量没有变多**：一切正常时仍然是每端口 15 秒最多探一次、一次不到 1KB；
  只有在"发现不对劲、还没定论"的那一小段才加密，一次故障最多多探几次、多花几 KB。

- **技术边界补上第 5 条**：安全软件（杀毒、企业 EDR）可能把这套脚本当成可疑程序拦下——
  它会写用户级环境变量、加开机启动项、在用户目录放脚本，看着确实像。处理办法是按安全软件的
  提示允许或加白名单，不要为它关掉防护。Mac 上对应的形态是 Gatekeeper 首次运行拦截。

- **故障排查里"装好后终端还是不能翻墙"的步骤写清楚了**：先新开一个窗口；如果还是旧值，
  才需要把终端程序整个关掉重开——已经开着的窗口不会自己变，这是操作系统的限制，不是本工具的
  问题。

## 其他

- 中英文说明、配图与版本号全部同步。
- 无破坏性改动：代理变量的写入与删除判据、快照还原、更新流程都与上一版一致，
  直接覆盖安装即可。

## 安装

下载你平台的包 → 解压到任意位置（文件夹随便改名）→ 进 `win`（Mac 进 `mac`）双击菜单 →
选 `1 安装 / 修复` → 看到"监控进程：已启动"就装好了。

已经装过旧版的，打开菜单选 `5 检查更新`，或者在菜单里选 `1 安装 / 修复` 覆盖一遍即可，
你自己的环境变量快照不受影响。
