## v1.5.2：中文说明的章节序号改成阿拉伯数字

### 改了什么

中文 README 的章节序号原先用汉字（「一、二、三……」），英文 README 用的是阿拉伯数字
（`1.` `2.` `2.5` `3.` …）。两份说明是同一文档的两个版本，序号体系不同会让对照阅读费劲。

本次把中文 README 的章节序号统一成与英文版同一套：`1.` 到 `13.`，日志一节为 `2.5`
（英文版原本就是这个编号），macOS 一节为 `12`，其下 `12.1` 至 `12.7` 不变。

### 同时改掉的引用

章节号一改，正文里的交叉引用必须跟着改，否则会指错章节。本次逐条核对并修正了：

- 中文正文：「见第十一节第 1 条」→「见第 11 节第 1 条」、「见第十二节」→「见第 12 节」、
  「见第十一节第 3 条」→「见第 11 节第 3 条」、「见第十二节 12.4」→「见第 12 节 12.4」、
  「先看第六节」→「先看第 6 节」。
- 英文正文：因序号整体后移（新增 `2.5` 的独立编号），macOS 一节由 `12` 变为 `13`，
  对应两处引用同步改为 `section 13` 与 `section 13.4`。

### 验证

- 目录锚点逐项校验：15 个目录项与 24 个标题全部一一对应，坏锚点 0 个（两份都过）。
  校验用的是与 GitHub 相同的 slug 规则，并先在未改动的英文版上跑通算法本身。
- 两份 README 章节数（24）与表格行数（58）仍然一致。
- 代码注释里不引用 README 章节号，本次不涉及代码；sh 语法、ps1 语法、编码红线三条门禁全绿。
