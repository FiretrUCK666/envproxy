# v2.1.0

这一版没有加新功能，全是修。要修的东西集中在两处：**它说它做到了，其实没做到**，以及**它慢得没必要**。

## 你会直接看到的变化

**查看状态快了六倍。** 以前点「查看状态」要等十秒左右，现在一秒半。原因不是网络慢，是更新检查在直连被限流之后，还要空等一条注定失败的网页兜底。现在限流会直接换一条出口重试，不再干等。

**卸载真的清干净了。** 这是一个会让你以为已经好了的故障：卸载时屏幕打印「已恢复到安装前的状态」，而 `ALL_PROXY` 和 `NODE_USE_ENV_PROXY` 两个变量还留在注册表里。它们指向一个已经关闭的本地端口，于是新开的终端里 `git`、`curl` 全部连不上，而你看不出原因。更糟的是它会自我加固——下次安装时这两个残留被当成「你原有的值」存进快照，从此每次卸载都会把它们还原回来。

**macOS 状态页不再误报「系统代理疑似残留」。** 那条检查的 curl 命令里夹了一行注释，把命令从中间截断了。于是它每次都拿不到结果、每次都判「系统代理是死的」，哪怕你的系统代理完全正常。这条提示是叫你去排查浏览器打不开的，误报会把人引向错误方向。

**macOS 上只绑 IPv6 的代理，端口显示终于对了。** 以前会显示「已注入 (127.0.0.1:1)」——从 `[::1]:7078` 里取到了 `::1` 中间那个 `1`。看起来一切正常，实际是一条完全错误的结论。

**macOS 上只写了 `.zshenv` 的用户，状态页不再说「没装」。** 安装实际写到 `.zshenv`，而状态页查的是 `.zshrc` 那一组。于是状态页让你「重跑一次安装」，而重跑也修不好，因为问题不在安装。

## 修掉的「以为有保护，其实没有」

这一版花了很多力气在测试和检查本身。它们不改变你看到的功能，但决定了下一次改动会不会悄悄弄坏东西。

| 原本以为 | 实际情况 |
|---|---|
| CI 在 Ubuntu 上跑完整测试 | 有一处直接访问 Windows 注册表，在 Linux 上会当场退出——**后面 124 条断言一条都没跑过** |
| mac 的 `launchctl` 注入有测试 | 替身把每次调用写进日志，但**从来没人读过那个日志**。9 行注入删掉任意几行，测试照样全绿 |
| mac 的握手判决有测试 | `test_http_proxy` 等函数在自检里**引用次数为 0**。把握手判据改成恒真也发现不了 |
| 三条门禁真的在查 | 注释写着「门禁 6 核对」，而门禁里**一次都没提过**那三张表 |
| 「裸变量路径」门禁在生效 | 它的正则只认一种写法，而生产代码里那种写法**一处都没有**——命中数 0，等于没开 |
| README 第 8 节清单被核对 | 删掉清单里整行 `mac\`，门禁照样通过，因为同块别处含「Mac」字样就能顶替 |
| 校验值大小写归有测试 | 断言用的是不区分大小写的比较，删掉 `.ToLower()` 照样通过 |
| 测试不碰你的真实环境 | `[2b]` 段往**真实**的安装快照键写值再删掉；自检还会在你的家目录留下 `.envproxy.bak` |

现在这些都有真实覆盖了。mac 侧自检的断言数在仓库里跑最多（含跨端共用的那批用例），在安装目录里跑会少一批并标注跳过——共用的用例文件随仓库走，不随安装包走。

## 两个「换个环境就失效」的修补

**配额用尽时会换一条出口重试。** GitHub 的匿名配额按来源 IP 计算。以前只有「连不上」才换出口，而「配额用尽」不换——可那恰恰是最该换的情况：实测直连出口已经用尽，同一个地址走上本机代理 468 毫秒就拿到了。现在限流也会换。

**网页兜底改成先走代理。** 这条路是 API 失败后的最后一道保障。而 github.com 的直连在受限网络里会整段超时——实测直连这一跳 21 秒才失败，走代理 390 毫秒。以前先试直连，等于让用户为一次注定超时的尝试买单。

## 修掉的其它问题

- **状态页的系统代理检查**：`/dev/tty` 打不开时的报错会漏到屏幕上（在定时任务、CI、管道里看得到莫名的 `No such device or address`）。同样的问题在更新确认处有四处。
- **macOS 自带的 BSD sed** 不认 `\|`（那是 GNU 扩展），一条兼容路径会静默失效。改用 `-E`。
- **三处中文文案** 用了 ASCII 双引号包中文，输出时引号被 shell 吃掉、两侧空格被吞。同时把这条检查从只扫 Windows 扩到两端——它一直没覆盖 mac，所以一直绿着。
- **`CONTRIBUTING.md` 里那条本地检查命令** 指向不存在的 `mac/tests/`，而且不报错：glob 不展开时命令照样返回 0，跑的人看屏幕没输出就以为过了。
- **`.gitignore`** 漏了两个代码真会创建的运行时文件，容易被 `git add -A` 带进仓库。
- **注释里的 `v2.1.0`**（一个当时并不存在的版本号）改成不依赖版本号的表述。

## 升级

打开菜单选「检查更新」，或者：

```
# Windows
powershell -ExecutionPolicy Bypass -File win\envproxy.ps1 -Update

# macOS
bash mac/envproxy.sh update
```

已经装着的用户直接升即可，不需要先卸载。升级走的是同一套校验：先对 GitHub 公布的 sha256、再比包内 `VERSION`、再确认库清单齐全，任何一项不过就中止且现版一个字节不动。

**如果你之前卸载过、发现代理变量没清干净**：这一版会自愈。卸载时会检查快照里那一条是不是我们写下的，是就不再还原。
