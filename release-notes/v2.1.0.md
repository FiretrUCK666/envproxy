# v2.1.0

这一版**没有新功能**，装上去用法完全一样。

修的是四件「屏幕说的和实际做的不一致」的事，其中两件会让**脚本判断错**——那是比看错更贵的错。

## 最重要的一条：卸载失败时，程序说「成功了」

**谁会遇到。** 卸载时你原来的代理设置没能写回去的人（被安全软件拦住、或组策略不让改注册表）。

**发生了什么。** 屏幕上明明打了 `[未完成] 你原来的代理设置没能写回去`，但程序的**退出码是 0**——也就是说，在脚本眼里这次卸载是成功的。

Windows 侧的原因是那行只写了一个 `return`，什么都没返回；而入口把返回值转成数字时，空值会变成 0。

**为什么这条最贵。** 那正是「你的备份还留着、需要你手动处理」的情形。如果谁写了个脚本：

```
envproxy.ps1 -Uninstall
if ($?) { 删掉备份目录 }
```

它会把**唯一一份备份也删掉**。设置没了，备份也没了。

**怎么修的。** 如实返回 1。macOS 侧同一处本来就是 `return 1`，现在两端一致了。

## 第二条：安装最后一步失败，也算装好了

**谁会遇到。** 终端同步那一步没做成的人——配置文件里的标记不成对，或者写不进去。

**发生了什么。** 屏幕打的是 `[4/4] 终端同步：写入失败`，最后却仍然打印「装好了」，退出码也是 0。

**怎么修的。** 这两条失败分支现在都会把结论记成失败。屏幕上还是一样的提示，只是退出码跟着变了。

## 第三条：连不上时的建议，给错了方向

**谁会遇到。** 检查更新时网络连不上的人。

**旧的说法。** 「可以打开翻墙软件让请求走代理再试一次。」

**为什么不对。** 这个工具本身的立场是「升级不该要求你开着翻墙软件」。而且真正连不上的时候，先要排除的是**网络本身通不通**，不是「有没有挂代理」——后者会让本来就通的人白折腾一圈。

**新的说法。** 「可以先确认能正常上网（打开常用的网页试一试），再重试一次；也可以稍后再试。」

## 第四条：macOS 上有一处提示会打印出星号

**谁会遇到。** macOS 上停用代理时变量没清干净的人。

**发生了什么。** 那条提示原本按网页排版的习惯写成了「代理变量**没能清除干净**」，而终端不认这套语法——你在屏幕上看到的是两个星号原样打出来。

**怎么修的。** 改成和其它提示一致的 `[未完成]` 开头。

## 顺便把底下的结构理了一遍

这一部分你看不到，但它决定了以后改起来会不会一动手就崩。

**三个库之间原来是个圈。** 「运行时」要问「更新」版本、「更新」要调「安装」、「安装」又要停「运行时」——三者首尾相接。这类结构最麻烦的地方是：单独读任何一个文件都看不出它依赖什么，改动一处会在另一处炸。

现在把共享的能力（日志、目录路径、项目身份查询）下沉到最底层，「更新」不再认识「安装」，改由入口把能力递进去。

**门禁原来只认「两个库互相调用」这一种圈。** 三个库连成的圈它看不见——实测把上面那个三库环喂给它，它照样报绿。现在改成找任意长度的环，报出来时会逐条列出是哪些函数把两层连起来的。

**有些门禁在「查一个不存在的东西」时是绿的。** 比如检查某个常量两侧是否一致，取不到那个常量时它只打印一句「找不到」就跳过，然后打印「通过」。常量被改名这种情况反而永远抓不到。现在取不到就直接判失败。

**体量门禁量错了对象。** 那条「这个文件不许超过 54 KB」的检查，量的是上一个提交里的版本，不是你现在改的这份。改完没提交时它看的是旧的。现在量工作区。

## 验证

- Windows 自检：PowerShell 7 全过
- macOS 自检：全部通过，其中新增 5 条
- CI：ubuntu（pwsh 7）与 windows-latest（PowerShell 5.1）各跑一遍，全绿

这版新增的断言：

- 开机自启配置里**必须**有 `RunAtLoad`（否则重开电脑监控不会起来）
- 同一条配置里**必须没有** `KeepAlive`（有它就会每 10 秒重启一次）
- 开机自启配置的 XML 骨架完整（缺标签会让系统静默拒收，而屏幕照样说装好了）
- 运行时目录能被重建，且重复创建不报错
- 操作锁的名字带 `Global\` 前缀、不同用途是两把不同的锁

新增的断言都做了反向验证：故意改坏一次，确认它会红。其中「锁名带当前用户 SID」这一条只在拿得到 SID 的系统上检查——它是 Windows 专属概念，在 Linux 上没有，写死会让 CI 必红。

## 兼容性

没有不兼容改动。没有新增依赖。变量集合、注入判据、阈值、菜单编号、帮助内容、状态页布局都没动。

唯一可能被脚本感知的变化就是上面说的**退出码**：安装或卸载有步骤没做成时，原来报 0、现在报 1。这是修正，不是破坏——按项目的退出码约定，`0` 本来就该表示「达成目的」。
