# v2.1.0

安装快了十倍，菜单和帮助改成不用滚动，发版前又查出几个会弄坏你设置的问题，一并修了。

标成 2.1 而不是 2.0.0 的补丁版，因为菜单和帮助的用法变了（多了翻页、配色、看全部）。程序行为没有破坏性变化，从 2.0.0 升上来不用做任何额外操作。

## 装得快了

第一次安装以前要等将近一分钟，现在六秒左右。

原因是写环境变量的方式换了：以前每写一个变量都要等系统确认一次（每次约 11 秒），5 个变量就是 56 秒。工具本来就是整批写完统一通知系统一次，前面那些等待都是白等。

顺带修好一个副作用：你原有的环境变量如果写过 `%USERPROFILE%` 这类引用，以前会被悄悄替换成固定路径，现在原样保留。

## 菜单和帮助不用滚屏了

菜单按用途分成三组：日常（1 安装 / 修复、2 查看状态、5 检查更新）、维护（3 停止监控、4 一键恢复、6 帮助）、退出（0）。

编号一个都没变，你记熟的还用得上。

帮助从「一整篇刷下来」改成一屏一个主题，一共 7 个：

1. 它是什么、怎么判断你在翻墙
2. 装完之后会发生什么
3. 单个窗口怎么接管 / 走公司代理
4. 让某一条命令不走代理
5. 菜单每个选项做什么
6. 日志在哪、文件夹结构
7. 觉得不对劲怎么办

进去先看目录，输编号看那一段。底部固定一行：

```
回车 = 返回目录    n = 下一个    p = 上一个    0 或 m = 回主菜单
```

`n` 和 `p` 翻到头会绕回去，按了总有反应。想从头读一遍，在目录页按 `a` 看全部。

## 有颜色了

按每行的用处自动分色：小标题青色、命令绿色、说明灰色、需要注意的黄色。

眼睛扫一遍就能找到要敲的东西，不用逐行读。

## 出问题时的提示说人话了

以前状态页会冒出「端口枚举失败」——那其实是正常行为（这一轮读不到端口，所以什么设置都没动），但「失败」两个字看着像坏了。现在写「这一轮没读到本机端口，所以没有改动任何设置（正常，会自动重试）」。

输错编号时提示会留在屏幕上（以前会被立刻清屏，只看得到屏幕闪一下）。

## 发版前查出来并修掉的问题

这些都是「看着正常、实际会弄坏东西」的那一类：

- **菜单在 Windows 上打不开**：发版前最后一轮检查发现的，一处判断写错导致无限递归，双击菜单只闪一行提示就退出。已修，并加了断言防止同类错误再出现。
- **Mac 菜单显示空白**：一项都没列出来，键位却还能用。
- **你的 `NO_PROXY` 引用会丢**：`%USERPROFILE%` 这类写法在注入和清理两个方向都会被展开成固定路径，换用户名后那条例外域名就失效。两个方向都修了。
- **写变量失败会谎报成功**：需要写 5 个却只写进 3 个，日志还说「已注入代理」。现在写失败会如实告诉你，并给出下一步。
- **安装某一步失败会中断后面所有步骤**：现在每步各自处理，一处失败不牵连其余。
- **「开机自启」会撒谎**：启动文件已经不存在了，状态页还说「已启用」。两端都修了。
- **安装时有两处同时写变量**：现在共用同一把锁。

## 两端对齐

以前有些不一致：Mac 安装说「会改这 4 处」却只显示 3 步、状态页的「已启用」判据只有 Windows 修了、非交互调用菜单的退出码两边不同。

这些现在都一致了。安装两端都是 4 步，与「会改这 4 处」一一对应。

## 升级

打开菜单选 `5 检查更新`。先告诉你新版本号和改了什么，你同意之后才安装。

升级不需要开翻墙软件。装之前会核对校验值，对不上就不装。只替换程序文件，你的文件、日志、运行标记都不会被碰。
