# v2.1.0

这一版主要做一件事：**把各个页面的样子统一起来**。另外修掉了两处会让工具
悄悄出问题的地方。

## 界面：不再「一屏一个样」

如果你用过之前的版本，可能有这种感觉：每一页看起来都还行，但放在一起就像
几个人分别做的——标题的横线长短不一样、退出提示有七八种说法、有的页面区块
糊在一起看不出边界。

这一版把这些收进了一套规矩。

### 标题横线长短一致了

以前同一个屏幕上能同时出现三种长度的横线。状态页最明显：顶部标题、中间的
「最近日志」、底部收尾，三根线宽度分别是 29 / 38 / 34 个字符，看起来像三个
不相关的部件拼在一起。

现在规则只有一条：**一屏之内所有横线一样宽**，宽度由标题决定，不够宽就补到
40 列。全站十几个页面用的是同一个函数，改一次全部生效。

### 退出提示统一说法

以前「怎么离开这一屏」有八种写法：

`0 = 返回主菜单`、`0 = 返回`、`按回车返回`、`按回车继续`、`按回车回菜单`、
`（按回车返回）`、`按 0 或 Esc 返回`、`看完按回车返回`

现在按「回到哪里」分三档，措辞只有一个来源。而且每一句都同时说清两件事：
**按什么键**、**回到哪里**。

### 高级功能页的三大块分开了

「给某个程序定规矩」「浏览器上不了网的时候」「本工具管不到的地方」这三块，
以前只靠一个小标题区分，中间没有视觉边界。现在块与块之间有一条分隔线。

### 状态页不再把「代理变量」印两遍

正常状态下，静态版状态页会把这一行打两次——一次在顶上、一次在中间，而且
顺序与实时刷新那版相反。按回车看和等它自己刷新，看到的是两张不同的屏。

现在每个标签只出现一次，顺序与实时版一致。

## 修掉的两处「悄悄出问题」

### Git Bash 窗口可能永远清不掉旧代理

`NO_PROXY` 这个变量的值里如果带换行（Windows 允许，手工编辑或复制粘贴都可能
带进来），写进中间那个状态文件时会把一条记录劈成两行。

Git Bash 的钩子逐行读，读到的是被截断的前半截，于是判定「这不是我们写的，
不许删」——那个窗口就永远停在一个已经死掉的端口上，而 `HTTP_PROXY` 照常被
清掉。结果是**半套变量**：`git`、`curl` 静默连一个不存在的地址。

现在写入时会把换行转义成 `%0A`，读的时候再还原。

### 新增变量时不会再漏改一处

Git Bash 的钩子里原本手抄了三份变量清单（哪些算我们的、大小写怎么对应、
怎么清除）。这三份和真正的变量表是两处独立的事实——将来加第 6 个变量时漏改
任何一处都不报错，只是那个变量在 Git Bash 里永远清不掉。

现在三份都从同一张表生成。实测加一个假想的第 6 个变量，三处会自动跟上。

## macOS 侧

### 系统代理读不出来时会如实说了

macOS 的「浏览器代理修复」有六种判定结论，Windows 有七种。少的那个是
**「读不出来」**——系统工具被拦、权限不足、输出认不出来。

以前遇到这种情况，那一层会**直接从清单里消失**。界面上看起来像「这个服务
根本没有代理设置」，而真相是「连工具都读不到」。两者对使用者的含义完全相反。

现在它会如实报一句「读不出来」，与「这是别人的代理」区分开。

## 内部整理

- 删掉五处没人调用的死代码（三个 Windows 函数、两个 macOS 函数）
- 合并了 macOS 侧两份逐字重复的 awk 判断
- 写开机自启动的函数补上了「写完读回确认」——与自愈路径同一套判据

## 升级

装过旧版本的，打开菜单选 **1 安装 / 修复** 即可。命令行工具里已有的代理变量
不受影响，不用重开窗口。
