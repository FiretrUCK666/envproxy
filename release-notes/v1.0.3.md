## v1.0.3：更新不再误判自己失败

**如果你是从 1.0.2 或更早的版本升级上来：更新完成后请再进 `win` 双击一次 `1-安装`。**
旧版的更新收尾会误判自己失败，进而把刚装好的监控掀掉；点一次 `1-安装` 就彻底归位
（重建监控、把开机自启动的记录写对）。从这一版起，更新会自己收好尾，不再需要这一步。

### 这一版包含

- 更新收尾成没成，改成**复读**判据：读安装根里的 `monitor\monitor.pid`，确认那个进程还活着、
  命令行指向安装根的主程序——是，就算收尾完成。退出码不再参与判断：Windows 自带的
  PowerShell 5.1 里，`Start-Process -PassThru` 之后读退出码得到的是空值，于是每次更新都被判成失败，
  白跑一遍兜底收尾，把刚起来的监控掀掉、把刚写对的路径记录改回去；
- 收尾真的没走完时，用**安装根里的新代码**再跑一次收尾，而不是本进程里那份旧代码
  （旧代码对当前文件布局的假设可能已经过时）；
- 再跑一次仍然起不来，如实说「监控未能确认运行，请再双击一次 `1-安装`」，不冒充成功；
- 回归自检加一节：收尾判据的反例——没有 pid 文件、pid 已死、pid 指向别的进程，都不算收尾完成。
