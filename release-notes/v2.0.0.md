菜单多了一个「帮助」，文档按普通人的理解方式重写了一遍。

标成 2.0 是因为文档几乎全改了：结构、说法、例子。程序行为没有破坏性变化，老版本升级上来不会有任何不适。

## 新的：6 帮助

装完放着不管，过几个月想改点什么，往往想不起来命令怎么写。现在打开菜单选 `6`，一屏看完：常用命令、三种窗口的区别、几个容易踩的坑。

也可以在终端直接调：

- Windows：`powershell -ExecutionPolicy Bypass -File envproxy.ps1 -Help`
- macOS：`bash envproxy.sh help`

## 文档重写

两条主线：说清楚，不啰嗦。

### 说清楚了

- **第 3 节的命令只影响当前窗口**，这一点以前只在 3.1 提过一次，现在整节开头就讲明白
- **`--noproxy` 只对 curl 有效**，以前写得含糊，别的工具该怎么写现在直接给例子
- **`$PROFILE` 是什么**、这条命令在做什么、适用于哪些 shell，都补上了
- **「装之前就开的窗口」和「装完之后开的窗口」**以前表格里两行分不开，现在分开了
- 一堆没解释就用的词去掉了：钩子、定位器、原子写入

### 不啰嗦了

- 第 0 节讲旧窗口为什么按回车，从三段压成两段
- 第 5 节的时间表和图注重复，合并
- 第 8 节的文件树只留你该关心的，七个库、入口细节都收起来

## 修的对不上

文档里几处说法和代码不一致，全部按实际行为改写：

| 原来写的 | 实际 |
|---|---|
| 日志上限 1MB | 200KB |
| 每 60 轮自愈 | 30 轮 |
| 访问 7 个站点全通才算数 | 任意 1 个通就算 |
| 改名后监控继续跑 | 监控会自己退出并清除变量 |
| 重复装连文件时间都不改 | 会重写开机启动文件 |
| 每 2 秒检查 | 直连时 3 秒 |
| 搜索范围是用户目录向下 6 层 | 只搜桌面、文档、下载、OneDrive、`.config` 这几个位置 |

## 修的功能问题

### 菜单可能少印一项

菜单的显示和它接受的编号以前是两份清单，加功能容易只改一处。现在共用一张表，加一项就一定显示出来。

### 帮助里的命令在 Windows 上跑不起来

帮助里写 `curl --noproxy "*"`，在 PowerShell 里这条是错的：`curl` 被当成了 `Invoke-WebRequest` 的别名。现在写 `curl.exe`。

### 一条测试是假的

「会不会误删你自己的代理」这段有四条断言，但它准备的数据有问题，四条走的其实是同一个分支：把判断逻辑整段删掉，它们照样全过。现在每条都摆好真实状态、只改被测那一项，也验证过故意改坏会立刻报红。
