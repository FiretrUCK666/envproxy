# v1.0.2

修掉两个会实际影响使用的问题，并把"页面承诺的时间"全部改成由代码常量推导。

## 这一版改了什么

- **探测量回到承诺值**：上一版把"发现异常就加密观察"做成了"每次探测成功都重新计时"，
  观察窗因此永不结束，探测实际每 5–6 秒就做一次——流量是承诺值的 2.5 倍左右。
  现在只在**结论真的翻转**（通变断、断变通）时才开始加密观察，平时老老实实 15 秒一次。
  实测：节点一直处于断开状态下连续跑 1 小时，探测 227 次（承诺上限 240 次）。

- **不再误删你自己设的变量**：判断"某个代理变量是不是本工具写的"，以前只看值的形状。
  如果你自己本来就设了 `NO_PROXY=localhost`，或者用 mitmproxy 之类在 127.0.0.1 上挂了一个
  代理，它会被当成"我们写的残留"定时删掉，日志还写着"回收残留"。现在以**安装时记下的原值**
  为准：装之前就有的，永远不动。

- **Mac 换端口不再误判**：Mac 版有个槽位复用的细节没清干净，换到新端口时可能沿用上一个端口的
  "通"结论，把刚探测失败的端口报成通的。已修，并补了专门的回归用例。

- **README 里每个时间都由代码常量推出来**：断开多久、连回多久、结论后还多盯几分钟，
  全部改由门禁从常量现场计算并与中英文两份 README 比对。以后改任何一个常量而忘记改文档，
  门禁会当场失败。同步修正了两处偏乐观的数字（"连回约 3 秒"应为 10–25 秒）。

- **系统代理残留检查补到 Mac**：Windows 上"查看状态"会提示系统代理是否指向一个死掉的本地端口
  （浏览器打不开、但终端正常的那种情况）。这条以前 Mac 上没有，现在补上了，判据一致。

## 其他

- 中英文说明、配图与版本号同步；`AGENTS.md` 的行为契约跟着更新。
- 无破坏性改动：代理变量的写入与删除判据、快照还原、更新流程都与上一版一致，
  直接覆盖安装即可。

## 安装

下载你平台的包 → 解压到任意位置（文件夹随便改名）→ 进 `win`（Mac 进 `mac`）双击菜单 →
选 `1 安装 / 修复` → 看到"监控进程：已启动"就装好了。

已经装过旧版的，打开菜单选 `5 检查更新`，或者在菜单里选 `1 安装 / 修复` 覆盖一遍即可，
你自己的环境变量快照不受影响。
